## Requisitos Previos 
* **Python:** Versión `3.10` o superior.
* **Gestor de Paquetes:** `pip` (o `conda`).
* **Entorno de Ejecución:** Jupyter Notebook, JupyterLab o VS Code con extensión de Jupyter.

 --- 
 
 ## Guía de Instalación y Configuración 
 
 Sigue estos pasos para preparar el entorno de ejecución en tu equipo local: 
 
 ### 1. Clonar o Descargar el Proyecto
Descarga el proyecto en tu máquina local:
```bash
git clone https://github.com/LorayAgustin/TrabajoEspecial_CienciaDeDatos.git
```

Y posicionate dentro de la carpeta raíz:

```bash
cd TrabajoEspecial_CienciaDeDatos
```

### 2. Crear un Entorno Virtual (Recomendado)
En linux:
```bash
python3 -m venv venv
```
Activacion:
```bash
source venv/bin/activate
```

### 3. Instalar las Dependencias
```bash
pip install -r requirements.txt
```

### 4. Ejecuta el Jupyter
Podes hacerlo abriendolo con el VS Code o sino ejecutando el siguiente comando para abrir el cuaderno:

```bash
jupyter-lab
```
